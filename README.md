# 🔢 Contador de Letra 'A'

## ✨ Sobre o Projeto
Este é um pequeno programa em **Java** que conta quantas vezes a letra 'a' aparece em uma palavra digitada pelo usuário. O programa ignora diferenças entre maiúsculas e minúsculas.

## 👨‍💻 Como Funciona
1. O usuário digita uma palavra.
2. O programa converte a palavra para minúsculas.
3. Ele percorre cada caractere da palavra e conta quantas vezes 'a' aparece.
4. Exibe a quantidade encontrada ou informa que a letra 'a' não foi encontrada.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Java
- **Ferramentas:** Scanner para entrada do usuário

## 💪 Como Executar
1. Copie o código e salve em um arquivo `ContadorDaLetraA.java`.
2. Compile o código com o seguinte comando:
   ```sh
   javac ContadorDaLetraA.java
   ```
3. Execute o programa:
   ```sh
   java ContadorDaLetraA
   ```
4. Digite uma palavra e veja quantas vezes a letra 'a' aparece!

## 🔗 Exemplo de Uso
```
Digite uma palavra: banana
A letra 'a' aparece 3 vezes na palavra.
```
